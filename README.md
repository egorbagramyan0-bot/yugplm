# ЮГ-ПЛМ — демо-версия сайта

Готовые статические файлы демо-версии для просмотра на Vercel. Собирается из основного проекта командой `npm run build:demo`.

- Сайт закрыт от поисковых систем.
- Блог и страница дистрибутивов показаны в текущем виде; админка и отправка заявок работают только на основном хостинге.

Vercel: Framework Preset — **Other**, Build Command — пусто, Output Directory — `.` (корень репозитория).
